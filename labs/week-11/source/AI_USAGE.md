# AI Usage

ใช้ Microsoft Copilot ช่วยตรวจสอบแนวทางการเชื่อม Node.js กับ SQLite, การเขียน Parameterized Query, Automated Tests, SQL Injection Test, Transaction, Index, Users Endpoint และการจัดโครงสร้างไฟล์สำหรับส่งงาน

ผู้จัดทำได้ตรวจสอบโค้ด รัน API ทดสอบฐานข้อมูล รัน Automated Tests และรัน Checker ด้วยตนเองก่อนส่งงาน
